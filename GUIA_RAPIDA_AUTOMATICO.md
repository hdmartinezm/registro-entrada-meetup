# ⚡ Guía Rápida - Sistema Automático

## 🔗 URL

```
https://d2l8hbgwgeo97f.cloudfront.net/registration-station.html
```

## 🚀 Proceso (15 segundos)

### 1. Escanear QR
- Presionar "Usar Cámara"
- Apuntar al QR del asistente
- Esperar "beep"

### 2. Esperar
- Sistema extrae datos automáticamente
- Genera badge automáticamente
- **NO hay confirmación**

### 3. Entregar
- Badge aparece listo
- Descargar o imprimir
- Entregar al asistente

## ⚡ Atajos

- **Siguiente:** Presionar "Siguiente Asistente" o esperar 5 segundos
- **Reintentar:** Si hay error, presionar "Reintentar"
- **Manual:** Si no tiene QR, ingresar URL manualmente

1. Mantener cámara activa entre escaneos
2. Tener varios dispositivos en paralelo

4. Tener impresora cerca

## ❓ Problemas

### Cámara no funciona
→ Usar entrada manual

### No extrae datos
→ Sistema continúa (badge con campos vacíos)

### Error al generar
→ Presionar "Reintentar"
