# 🎫 Diseño de Badge 3x2 Pulgadas - Impresora Térmica

## 📐 Especificaciones

### Tamaño:
- **3 x 2 pulgadas** (216 x 144 puntos a 72 DPI)
- Optimizado para impresoras térmicas
- Diseño horizontal (landscape)

### Layout:
```
┌─────────────────────────────────────────────────┐
│  AWS User Group Monterrey  [Header Azul Oscuro] │
├─────────────────────────────────────────────────┤
│                                                  │
│  [Columna Izquierda]      [Columna Derecha]     │
│                                                  │
│  Nombre Completo          ┌──────────┐          │
│  (Bold, 13pt)             │          │          │
│                           │    QR    │          │
│  Empresa                  │   Code   │          │
│  (Regular, 9pt)           │          │          │
│                           └──────────┘          │
│  Puesto                   Perfil Builder        │
│  (Italic, 8pt)                                  │
│                                                  │
│  @username                                      │
│  (Bold, Naranja, 9pt)                           │
│                                                  │
│                          ID: xxxxxxxx [Footer]  │
└─────────────────────────────────────────────────┘
```

## 🎨 Colores AWS

- **Header:** `#232F3E` (AWS Dark Blue)
- **Línea decorativa:** `#FF9900` (AWS Orange)
- **Username:** `#FF9900` (AWS Orange)
- **Nombre:** `#232F3E` (Dark)
- **Empresa:** `#333333` (Dark Gray)
- **Puesto:** `#666666` (Medium Gray)
- **Footer:** `#CCCCCC` (Light Gray)

## 📝 Elementos del Badge

### Header (28pt altura):
- Fondo azul oscuro AWS
- Texto blanco: "AWS User Group Monterrey"
- Fuente: Helvetica-Bold, 11pt
- Centrado

### Línea Decorativa (2pt altura):
- Color naranja AWS
- Separador visual

### Columna Izquierda (120pt ancho):
1. **Nombre Completo**
   - Helvetica-Bold, 13pt
   - Color: AWS Dark
   - Más prominente

2. **Empresa**
   - Helvetica, 9pt
   - Color: #333333
   - Opcional

3. **Puesto**
   - Helvetica-Oblique, 8pt
   - Color: #666666
   - Opcional

4. **Username**
   - Helvetica-Bold, 9pt
   - Color: AWS Orange
   - Formato: @username

### Columna Derecha (80pt ancho):
1. **QR Code**
   - 70x70 puntos
   - Enlace al perfil Builder Center
   - Sin margen
   - Color: Negro sobre blanco

2. **Texto QR**
   - "Perfil Builder"
   - Helvetica, 6pt
   - Color: #999999
   - Centrado debajo del QR

### Footer:
- Badge ID (primeros 8 caracteres)
- Helvetica, 5pt
- Color: #CCCCCC
- Centrado

## 🖨️ Optimización para Impresora Térmica

### Características:
- ✅ Sin márgenes (full bleed)
- ✅ Diseño compacto
- ✅ Texto legible en tamaño pequeño
- ✅ QR code optimizado (70x70pt)
- ✅ Alto contraste para impresión térmica
- ✅ Layout de dos columnas eficiente

### Ventajas:
- 📏 Tamaño estándar para badges de eventos
- 💰 Económico (menos papel/etiqueta)
- ⚡ Impresión rápida
- 🎯 Información esencial visible
- 📱 QR code fácil de escanear

- Rollo Brother DK-1201 (2.4" x 3.5")
- Etiquetas térmicas 3x2"

### Configuración:
- Tamaño: 3 x 2 pulgadas
- Orientación: Horizontal
- Márgenes: 0
- Calidad: Alta (300 DPI recomendado)
